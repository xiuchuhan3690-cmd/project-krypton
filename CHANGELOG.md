# Changelog

All notable public-distribution changes are recorded here. This is not a reconstruction of the complete private scientific-development history.

## 1.0.1

- Prepared the first formal GitHub Release from the corrected public `main` branch.
- Enforced deterministic LF checkout behavior across Linux and Windows, including fresh `core.autocrlf=true` clones.
- Preserved the complete v1.0 scientific scope, numerical demo, validation debt, and rights-safe distribution boundary without scientific-semantic change.
- Updated release identity, citation, documentation, CI package paths, and measured wheel/sdist membership contracts to 1.0.1.

Historical note: the immutable `v1.0.0` tag records a controlled publication attempt halted after discovery of a Windows checkout line-ending defect. No v1.0.0 GitHub Release, assets, PyPI publication, DOI, or Zenodo deposition was created.

## 1.0.0 — tagged publication attempt, not a formal release

- Prepared the first rights-safe public Project Krypton research-software prototype.
- Published the generic typed architecture, guards, public schemas, and synthetic C0 demonstration.
- Added hybrid repository, wheel, Dockerfile, and local-evidence-pack boundaries.
- Added repository-independent package resources and `krypton-info` / `krypton-demo` entry points.
- Excluded all external scientific data and private C1-C3B scientific artifacts from distribution.
- Preserved C3B as `RESTRICTED_COMPLETE`, route gate `USABLE_WITH_STATED_SCOPE`, maturity `EXTERNAL_DESCRIPTIVE_SUPPORT`, with Rows 30 and 31 BLOCKED.
- Added public documentation, citation metadata, contribution/security guidance, and machine-readable release/test manifests.

The public `v1.0.0` tag is preserved unchanged as historical provenance. Publication stopped before a GitHub Release or release assets were created. Project Krypton was not published on PyPI, and no DOI or Zenodo deposition was created.
